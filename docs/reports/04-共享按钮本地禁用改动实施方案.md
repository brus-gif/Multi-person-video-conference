## 一、需求汇总（全部经用户确认）

- **A（本地禁共享）**：本地演示（未联网）共享按钮置灰禁用、不可按下，提示"仅联网可用"。
- **B（共享期禁摄像按钮）**：联网共享开启 → 默认自动关摄像头（cam=false 广播，原联动保留）；**共享期间摄像头按钮置灰禁用**；共享关闭后恢复可用。
- **C（规则0：推流连接单点收口）**：`frameReady→onSelfFrameForNetwork` 只由**摄像头按钮状态**决定；收口为幂等 `syncSelfVideoNetwork()`；在启动/入会/源重建/共享恢复时机按按钮状态刷新；**不恢复瓦片路径（602-604）连接**；摄像头默认开 → 入会即推流（覆盖 H2）。
- **D（离会状态保持）**：离会/断开 → 共享必关（按钮未勾选+置灰）、摄像头按钮解除禁用、**摄像头状态保持会议结束时状态（不自动开回）**、宫格/瓦片按启动默认配置重建但摄像头状态不被冲掉。

```cpp
void MainWindow::syncSelfVideoNetwork()
{

        return;
    // 幂等：先断开全部匹配，避免重复连接导致同一帧被推多次

}
```

```cpp
void MainWindow::setOnlineMode(bool online)
{
    const bool changed = (m_online != online);
    m_online = online;

    // A/B/D：共享按钮可用性随会话形态
    if (m_shareBtn) {
        const bool wasBlocked = m_shareBtn->signalsBlocked();
        m_shareBtn->blockSignals(true);
        m_shareBtn->setEnabled(online);
        if (!online)
            m_shareBtn->setChecked(false);    // 离会：共享复位为未勾选（共享必关）
        m_shareBtn->blockSignals(wasBlocked);
    }
    // B/D：离会（含共享中离会）解除摄像头按钮禁用；入会也保证可用
    if (m_camBtn) {
        m_camBtn->setEnabled(true);
        m_camBtn->setToolTip(QString());

    if (m_demoSection) m_demoSection->setVisible(!online);
    if (m_demoNote)    m_demoNote->setVisible(!online);
    if (m_networkBtn)

                                          : QStringLiteral("联网会议"));
```

## 四、回归用例（实施后验证）
1. 本地演示：共享灰、摄像头可点。
2. 入会（未点任何按钮）：摄像头默认开 → **对方能看到我（H2 修复）**；展示状态=服务器快照。
3. 共享开（联网）：摄像自动关→远端 cam=false；摄像按钮灰+提示"共享中不可用"；点它无响应。
4. 共享关：摄像按钮先恢复可点；共享前开→自动恢复（画面/推流恢复）；共享前关→保持关。
5. 共享中离会/掉线：回本地——共享按钮灰+未勾选、标题无残留、无残留推流、**摄像头按钮可点但摄像保持关**、宫格=4 人本地演示（摄像头状态未被冲掉）。
6. 会议中未共享直接离会（摄像开着）：回本地后**摄像头仍开**（保持会议时状态）。
7. 设置中切换摄像头设备（在线、摄像开）：新源推流自动接续（C 覆盖，无需再点按钮）。
8. 再次入会往返多次：按钮可用性/勾选态干净；无重复推帧（可抓服务端日志比对帧号）。
